# SAR Calculator Demo

Static SAR calculator website for GitHub Pages.

## Deploy on GitHub Pages

1. Create a new GitHub repository, for example `sar-calculator`.
2. Upload these files:
   - `index.html`
   - `style.css`
   - `script.js`
3. Go to `Settings` > `Pages`.
4. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.
6. Open the GitHub Pages link after it finishes deploying.

This is a front-end demo only. It does not connect to BigQuery or run a backend.
